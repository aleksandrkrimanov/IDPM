ГОТОВАЯ ПАПКА ДЛЯ GITHUB PAGES

1. Распакуй архив.
2. Открой существующий репозиторий страницы → Add file → Upload files.
3. Загрузи СОДЕРЖИМОЕ папки krimanov-principle в корень ветви, из которой публикуется GitHub Pages.
   index.html, breakthroughs.html, style.css, robots.txt, sitemap.xml, .nojekyll и папку assets.
   Не загружай внешнюю папку krimanov-principle целиком.
4. Подтверди изменения (Commit changes).
5. Если Pages ещё не настроен: Settings → Pages → Deploy from a branch → нужная ветвь → /(root) → Save.
